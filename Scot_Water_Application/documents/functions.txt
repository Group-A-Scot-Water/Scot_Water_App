1. Create a folder called "Functions"

2. In this folder, create AT LEAST 8 files: 
	i.		globalVariables.cs -> to store the variables globally
	ii.		inputValidation.cs -> to store the functions related to input validation, such as validateEmail(), validatePassword(), validateMeterReading(), etc.
	iii.	databaseIO.cs -> to store the functions related to database input and output, such as loadBusinessNames(), getBusinessInfo(), submitMeterReadingToDatabase(), submitBillToDatabase(), etc.
	iv.		calculations.cs -> to store the functions related to calculations, such as calculateBill()
	v.		dataDisplay.cs -> to store the functions related to displaying data into the forms, such as displayBusinessInfo(), displayCurrentWaterCharge(), etc.
	vi.		errorMessageDisplay.cs -> to store the functions related to displaying error messages, such as displayErrorMessage()
	vii.	UIEffect.cs -> to store the functions related to UI effects, such as buttonHoverEffect()
	viii.	commonMethods.cs -> * to store the functions to be used globally 
								** CHING will consolidate all nessary functions from the above files into this file
